# dbt Learning with Databricks
A hands-on project exploring dbt and Databricks.
## Tech Stack
Python, SQL, dbt Core, Databricks, and Git.
## Features
SQL models for date, product, sales, and store data.
Data tests for uniqueness, null checks, and accepted values.
Seeds load local CSV files into Databricks tables using `dbt seed`.
Snapshots track historical record changes using `dbt snapshot`.
Run models and tests using `dbt run` and `dbt test`.
